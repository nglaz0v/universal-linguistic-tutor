## 🎯 О проекте

**Polyglot RAG Tutor** — это интеллектуальный ассистент для изучения языков, построенный на архитектуре **Retrieval-Augmented Generation (RAG)**. 

Проект реализован в **двух вариантах развертывания**, демонстрирующих гибкость архитектуры:
1. **Web-интерфейс (Streamlit + Ollama):** Полностью локальное, приватное решение с нулевой стоимостью API.
2. **Мессенджер-бот (VK + OpenAI):** Облачное решение для быстрого отклика и удобства пользователей в привычной среде.

### 💡 Проблема
Современные LLM катастрофически галлюцинируют при работе с:
- **Редкими естественными языками** (белорусский, эсперанто)
- **Вымышленными языками** (синдарин Толкина)
- **Языками со сложной морфологией** (мутации согласных, i-аффония)

Модель часто смешивает правила разных языков (перекрестное загрязнение контекста) или придумывает исключения там, где их нет.

### ✅ Решение
Архитектура с **двухуровневой изоляцией контекста**:
1. **На уровне данных (Metadata Filtering):** Каждый язык хранится в отдельной коллекции ChromaDB. Векторный поиск физически ограничен метаданными `{"language": "..."}` и не может подтянуть чужой контекст.
2. **На уровне промпта (Prompt Engineering):** Системный промпт содержит жесткие инструкции для LLM игнорировать нерелевантные данные и честно признавать отсутствие информации в базе.

## 🚀 Ключевые возможности

- 🧠 **RAG с изоляцией контекста** — 4 независимых языковых домена в одной системе.
- 🛡️ **Защита от галлюцинаций** — строгие правила для каждого языка (запрет на выдумывание слов в синдарине, указание на отсутствие исключений в эсперанто).
- 🔬 **Морфемная декомпозиция** — алгоритмический разбор слов на корни и аффиксы.
- 📖 **Контекст чтения** — примеры из литературы, новостей и лора (а не только бытовые фразы).
- 🎓 **Интерактивная педагогика** — генерация упражнений с пошаговой проверкой ответов.
- 🔄 **Гибкость развертывания** — выбор между локальным инференсом (Ollama) и облачным API (OpenAI).

## 🏗️ Архитектура

Проект поддерживает два пайплайна инференса:

### Вариант А: Локальный Web UI (Streamlit + Ollama)
```text
[Пользователь] 
      │
      ▼
[Streamlit UI] ──(локальный HTTP)──> [Ollama Server]
      │                              - LLM: qwen2.5:7b
      │                              - Embeddings: nomic-embed-text
      ▼
[LlamaIndex RAG]
      │
      ▼
[ChromaDB] (Локальное хранилище с фильтрацией по метаданным)
```

### Вариант Б: Мессенджер-бот (VK + OpenAI)
```text
[Пользователь в VK] 
      │
      ▼
[vkbottle Bot] ──(HTTPS)──> [OpenAI API]
      │                     - LLM: gpt-4o / gpt-3.5-turbo
      │                     - Embeddings: text-embedding-3-small
      ▼
[LlamaIndex RAG]
      │
      ▼
[ChromaDB] (Локальное или облачное хранилище с фильтрацией по метаданным)
```

## 📦 Установка и запуск

### 1. Клонирование и подготовка окружения
```bash
git clone https://github.com/your-username/polyglot-rag-tutor.git
cd polyglot-rag-tutor
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или venv\Scripts\activate (Windows)
pip install -r requirements.txt
```

### 2. Генерация базы знаний
Запустите скрипты для создания 4 папок с 15 Markdown-документами в каждой (60 документов суммарно):
```bash
python generate_kb_french.py
python generate_kb_belarusian.py
python generate_kb_esperanto.py
python generate_kb_sindarin.py
```

---

### 🚀 Вариант А: Запуск локального Streamlit + Ollama
*Идеально для демонстрации приватности и работы с локальным железом.*

1. Установите [Ollama](https://ollama.com/) и скачайте модели:
   ```bash
   ollama pull qwen2.5:7b
   ollama pull nomic-embed-text
   ```
2. Запустите приложение:
   ```bash
   streamlit run app.py
   ```
   *Откройте браузер по адресу: `http://localhost:8501`*

---

### 🚀 Вариант Б: Запуск VK-бота + OpenAI
*Идеально для демонстрации продуктового сценария и облачной интеграции.*

1. Создайте файл `.env` в корне папки `vk_bot/`:
   ```env
   VK_GROUP_TOKEN=ваш_токен_группы_vk
   OPENAI_API_KEY=sk-ваш_ключ_openai
   ```
   *(Токен VK должен иметь права `messages` и `manage`)*
2. Запустите бота:
   ```bash
   cd vk_bot
   python main.py
   ```

## 💬 Примеры использования (Сценарии для Демо)

### 🧝 Сценарий 1: Синдарин и проверка изоляции
**Запрос:** *"Как будет 'орки' во множественном числе и почему?"*
**Ответ:** Ассистент извлекает правило **i-аффонии** из `sindarin_kb` и объясняет: `orch` → `erych`. 
*Трик для демо:* Спросите: *"А как это правило работает в Квенья?"*. Ассистент ответит: *"Это правило Синдарина. В предоставленных материалах по Квенья информация отсутствует, но в Квенья множественное число образуется иначе..."* (демонстрация защиты от галлюцинаций).

### 🟢 Сценарий 2: Эсперанто и декомпозиция
**Запрос:** *"Разбери слово malkomprenebla"*
**Ответ:** Ассистент выдает таблицу: `mal-` (противоположность) + `kompren` (понимать) + `-ebl-` (возможность) + `-a` (прилагательное) = "непонятный".

### 🇫🇷 Сценарий 3: Интерактивная педагогика (VK или Web)
**Запрос:** *"Дай упражнение на Passé Composé"*
**Ответ:** Ассистент генерирует ровно 5 заданий и пишет: *"Жду твои ответы! Напиши их, и я проверю, либо попроси 'дай ключи'"*. (Демонстрация управления поведением LLM через промпт).

## 📊 Сравнение вариантов развертывания (Оценка стоимости)

| Параметр | Вариант А: Streamlit + Ollama | Вариант Б: VK Bot + OpenAI |
| :--- | :--- | :--- |
| **Стоимость LLM** | **$0.00** (Локальный инференс) | ~$0.01 - $0.03 за запрос (GPT-4o) |
| **Стоимость Embeddings** | **$0.00** (`nomic-embed-text`) | ~$0.0001 за запрос (`text-embedding-3-small`) |
| **Требования к железу** | Высокие (нужен GPU или мощный CPU для 7B+) | Низкие (работает даже на Raspberry Pi) |
| **Приватность данных** | **Максимальная** (данные не покидают ПК) | Стандартная (политика конфиденциальности OpenAI) |
| **Скорость ответа** | 5-15 сек (зависит от железа) | 1-3 сек (зависит от сети) |
| **Итоговый бюджет (мес.)** | **$0** | **~$5-10** (при 500 запросах в день) |
