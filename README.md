## 🎯 О проекте

**Polyglot RAG Tutor** — это интеллектуальный ассистент для изучения языков, построенный на архитектуре **Retrieval-Augmented Generation (RAG)**. Проект решает ключевую проблему мультиязычных LLM: **перекрёстное загрязнение контекста** (cross-contamination), когда правила одного языка ошибочно применяются к другому.

### 💡 Проблема

Современные LLM катастрофически галлюцинируют при работе с:
- **Редкими естественными языками** (белорусский, эсперанто)
- **Вымышленными языками** (синдарин Толкина)
- **Языками со сложной морфологией** (мутации, i-аффония)

Модель часто смешивает правила французского субжонктива с эльфийскими мутациями или придумывает исключения там, где их нет (например, в эсперанто).

### ✅ Решение

Архитектура с **двухуровневой изоляцией контекста**:
1. **На уровне кода**: каждый язык хранится в отдельной коллекции ChromaDB с метаданными `{"language": "..."}`. Векторный поиск физически не может подтянуть чужой контекст.
2. **На уровне промпта**: системный промпт содержит жесткие инструкции для LLM игнорировать нерелевантные данные и честно признавать отсутствие информации.

## 🚀 Ключевые возможности

- 🧠 **RAG с изоляцией контекста** — 4 независимых языковых домена
- 🛡️ **Защита от галлюцинаций** — строгие правила для каждого языка
- 🔬 **Морфемная декомпозиция** — разбор слов на корни/аффиксы (эсперанто, синдарин)
- 📖 **Контекст чтения** — примеры из литературы, новостей, лора
- 🎓 **Интерактивная педагогика** — генерация упражнений с проверкой ответов
- 💰 **Экономичность** — локальные эмбеддинги (бесплатно), оплата только за финальный чат

## 📦 Установка и запуск

### 1. Клонирование и зависимости

```bash
git clone https://github.com/your-username/polyglot-rag-tutor.git
cd polyglot-rag-tutor

# Создание виртуального окружения (рекомендуется)
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка API-ключа

Создай файл `.streamlit/secrets.toml`:

```toml
OPENAI_API_KEY = "sk-your-api-key-here"
API_BASE_URL = "https://api.smartbuddy.ru/v1"
LLM_MODEL_NAME = "gpt-4o-mini"
EMBEDDING_MODEL_NAME = "text-embedding-3-small"
```

**Или** через переменную окружения:

```bash
export OPENAI_API_KEY="sk-your-api-key-here"  # Linux/Mac
set OPENAI_API_KEY=sk-your-api-key-here  # Windows CMD
$env:OPENAI_API_KEY="sk-your-api-key-here"  # Windows PowerShell
```

### 3. Генерация базы знаний

Если у тебя ещё нет папок с документами, запусти скрипты:

```bash
python generate_kb_french.py
python generate_kb_belarusian.py
python generate_kb_esperanto.py
python generate_kb_sindarin.py
```

Это создаст 4 папки с 15 Markdown-файлами каждая (60 документов суммарно).

### 4. Запуск приложения

```bash
streamlit run app.py
```

Открой браузер по адресу: `http://localhost:8501`

## 💬 Примеры использования

### 🧝 Синдарин: Разбор множественного числа

**Запрос:** *"Как будет 'орки' во множественм числе и почему?"*

**Ответ ассистента:**
> Во множественном числе слово **orch** (орк) становится **erych**.
> 
> Это происходит из-за правила **i-аффонии**: древнее окончание *-i* исчезло, но изменило гласную в корне.
> 
> | Единственное | Множественное | Правило |
> |--------------|---------------|---------|
> | o            | y             | orch → erych |

---

### 🟢 Эсперанто: Морфемная декомпозиция

**Запрос:** *"Разбери слово malkomprenebla"*

**Ответ ассистента:**
> Слово **malkomprenebla** разбирается на морфемы:
> 
> - **mal-** (префикс противоположности)
> - **kompren** (корень: понимать)
> - **-ebl-** (суффикс возможности)
> - **-a** (окончание прилагательного)
> 
> **Значение:** "непонятный" (дословно: "не-понимаемо-возможный")

---

### 🇫🇷 Французский: Интерактивное упражнение

**Запрос:** *"Дай упражнение на Passé Composé"*

**Ответ ассистента:**
> Вот 5 заданий на Passé Composé:
> 
> 1. Переведи: "Вчера я съел яблоко"
> 2. Вставь вспомогательный глагол: "Hier, j' ___ mangé une pomme"
> 3. Выбери правильную форму: "Nous (avons/être) allé au cinéma"
> 4. Преобразуй в Passé Composé: "Je lis le livre"
> 5. Найди ошибку: "Elle est parti hier"
> 
> **Жду твои ответы! Напиши их, и я проверю, либо попроси 'дай ключи'**

## 🛡️ Системный промпт

Системный промпт — сердце проекта. Он содержит:

1. **Роль и миссию** — "Универсальный Лингвистический Тьютор"
2. **Архитектуру изоляции** — жесткие правила игнорирования чужого контекста
3. **Принципы обучения** — структурированность, декомпозиция, контекст чтения
4. **Формат упражнений** — ровно 5 заданий с интерактивной проверкой
5. **Защиту от галлюцинаций** — специфичные триггеры для каждого языка

Полный текст промпта находится в файле `app.py` в переменной `SYSTEM_PROMPT`.
